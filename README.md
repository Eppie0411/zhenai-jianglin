# 真爱降临 · 梦女向小房间

一个只属于你和 ta 的本地小站。所有内容存在这台设备的浏览器里，不联网、不上传。

## 怎么打开

双击 `index.html`，用浏览器打开就行（推荐 Chrome / Edge / Safari）。
想放到网上，把整个文件夹丢给任意静态托管即可，无需构建。

## 里面有什么

| 分区 | 能做什么 |
| --- | --- |
| 主页 | 头像 / 昵称 / 简介、今天的日期与「今日一签」、八个入口 |
| 字卡传讯 | 给每位角色建独立字卡库（能量 / 答案 / 对话），抽卡翻牌、接住对话回一句、抽卡记录 |
| 记账 | 收入支出、分类与自定义分类、本月统计、分类排行、最近 7 天柱状图 |
| 日记 | 日期 + 心情 + 正文，列表、搜索、编辑、单篇大图阅读 |
| 游戏日常 | 记游戏名与今天做了什么，按游戏聚合、时间线筛选 |
| if 线建设 | 一条 if 线 = 设定 + 若干片段，可「读一遍」成排版模式 |
| 稿件展示 | 上传图片 + 标题 / 文案 / 署名 / 日期，三种卡片样式，点开是可直接截图的大图 |
| 小游戏 | 记忆翻牌、点点小猫、接住星星，都有 简单 / 普通 / 挑战 |
| 背景音乐 | 右下角小光盘，默认三段程序生成的纯音乐，也能导入自己的音频 |

## 小提示

- 右上角的风车按钮循环换配色；「小房间」里可以精确挑色系（含夜色）。
- 小光盘点一下展开面板并开始播放；导入的本地音频只在这一次打开有效。
- 「小房间 → 填点示例内容」可以先放进几笔示例看看效果，不会覆盖已有内容。
- 数据只在本地，换设备前记得「导出备份」；清空全部前也建议先导一份。
- 手机端顶栏是两行（站名 + 导航），字卡库里点一行就能改，右边的画笔改、垃圾桶删；角色旁边的画笔可以改称呼、换小圆点颜色，或者整个删掉。
- 手机上小游戏、稿件详情都已适配竖屏。

## 文件结构

```
index.html        页面骨架与顶栏
css/base.css      变量、主题色、通用组件、顶栏、主页、音乐
css/modules.css   各模块与游戏的样式
js/store.js       本地存储、工具函数、弹窗与图标
js/app.js         路由、主页、小房间设置、示例数据
js/cards.js       字卡传讯
js/ledger.js      记账
js/diary.js       日记
js/gamelog.js     游戏日常
js/ifline.js      if 线建设
js/showcase.js    稿件展示
js/games.js       三个小游戏
js/music.js       背景音乐（Web Audio 生成 + 本地导入）
```

改颜色：`css/base.css` 顶部的 `:root` 变量，或 `html[data-theme="..."]` 里那几组。
加字卡类型 / 换游戏难度参数：`js/cards.js` 的 `TYPES`、`js/games.js` 里的 `config`。
